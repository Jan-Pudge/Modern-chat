# Домашнє Завдання 12: Відеокружечки та Курсорна Пагінація у Modern Chat 📹⚡️💬

Це домашнє завдання є логічним та технічним продовженням розробки мобільного месенджера **Modern Chat**.
- Базова частина, авторизація та кімнати побудовані у **ДЗ 7** (`lesson-07-module-05/docs-home-work-modern-chat`).
- Редагування/видалення повідомлень, відправка фото у Convex Storage та індикатор набору тексту додані у **ДЗ 8** (`lesson-08-mosule-05/home-work-08`).
- Відповіді на повідомлення (Swipe-to-Reply) та кастомізація профілів реалізовані у **ДЗ 9** (`lesson-09-module-06/home-work-09`).
- Свайп карток кімнат для видалення реалізовано у **ДЗ 10** (`lesson-10-module-06/home-work-10`).
- Голосові повідомлення (`expo-audio`) та реакції емодзі у реальному часі додані у **ДЗ 11** (`lesson-11-module-07/home-work-11`).

У цьому домашньому завданні ми виводимо наш месенджер на рівень топових продакшн-додатків (**Telegram**, **WhatsApp**):
1. Додаємо **відеоповідомлення у кружечку (Telegram-style Video Notes)** зйомки з камери, круглим прев'ю та плавним відеоплеєром із круговим прогрес-баром.
2. Впроваджуємо **високопродуктивну курсорну пагінацію (Cursor-based Pagination)** для інвертованого списку повідомлень, що дозволяє миттєво відкривати чати з десятками тисяч повідомлень без навантаження на пам'ять та підвисань інтерфейсу.

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo SDK 52+ (Expo Router v4)
- **Робота з камерою:** [`expo-camera`](https://docs.expo.dev/versions/latest/sdk/camera/) (компонент `CameraView` з підтримкою запису відео)
- **Відтворення відео:** [`expo-video`](https://docs.expo.dev/versions/latest/sdk/video/) (`VideoView` та `useVideoPlayer`)
- **Векторна графіка:** `react-native-svg` (для кругового індикатора тривалості відеокружечка)
- **Бекенд & Realtime DB:** [Convex](https://convex.dev) (`usePaginatedQuery`, `paginationOptsValidator`, `.paginate()`)
- **Хмарне сховище файлів:** Convex Storage (для збереження `.mp4` відеофайлів)
- **Стилізація:** Tailwind CSS (NativeWind v4) з єдиною палітрою кольорів `constants/theme.ts`
- **Іконки:** `@expo/vector-icons` (`Ionicons`)

## 📋 Чекліст виконання для студента

### 1. Відеокружечки в чаті (Інструкція 14):
- [ ] Встановлено та налаштовано бібліотеки `expo-camera`, `expo-video` та `react-native-svg`.
- [ ] Додано системні дозволи для камери та мікрофона у конфігурацію `app.json`.
- [ ] У `convex/schema.ts` таблицю `messages` розширено полями `videoUrl`, `videoStorageId`, `videoDuration`, `isVideoNote`.
- [ ] На бекенді реалізовано мутацію `sendVideoNoteMessage` для збереження круглого відео.
- [ ] Створено модальний компонент запису кружечка `VideoNoteRecorder.tsx` з круглим оглядовим вікном, таймером до 60 секунд та кнопкою перемикання камери.
- [ ] У `ChatInput.tsx` додано кнопку для запуску запису відеокружечка (або перемикання режимів мікрофон / камера).
- [ ] Створено компонент відтворення `VideoNotePlayer.tsx`: ідеально круглий плеєр із круговим прогрес-баром, автовідтворенням без звуку та увімкненням звуку при натисканні.
- [ ] Кружечки відображаються коректно у `MessageBubble.tsx` як для відправника, так і для отримувача.

### 2. Пагінація історії чату (Інструкція 15):
- [ ] У `convex/messages.ts` створено пагінований запит `getPaginatedMessages` з використанням `paginationOptsValidator` та сортуванням `order("desc")`.
- [ ] В екрані чату `app/chat/[id].tsx` старий виклик `useQuery(api.messages.getMessages)` замінено на `usePaginatedQuery(api.messages.getPaginatedMessages, ...)`.
- [ ] Список повідомлень налаштовано через `<FlatList inverted={true} ... />`.
- [ ] Дозавантаження попередніх повідомлень викликається через `onEndReached={handleLoadMore}` при скролі вгору.
- [ ] Під час довантаження старих повідомлень у шапці інвертованого списку показується акуратний `ActivityIndicator`.
- [ ] Чат відкривається миттєво навіть при наявності тисяч повідомлень у кімнаті.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Кнопка безпечного очищення або виходу з кімнати (Hold-to-Confirm):**
   - Створіть або підключіть компонент `HoldToConfirmButton` на `react-native-reanimated` для виходу з чату або видалення кімнати з утриманням на 1.2 секунди.
2. **Жест перемикання камери під час запису (Double-Tap to Flip):**
   - Додайте подвійний тап по екрану під час запису кружечка для швидкого перемикання між передньою та задньою камерами без переривання запису.
3. **Тактильний відгук (Haptic Feedback):**
   - Використовуйте `expo-haptics` при старті запису кружечка, досягненні ліміту часу (60 секунд) та при успішному надсиланні.

## 💡 Поради щодо тестування

- Для тестування камери та мікрофона обов'язково використовуйте **фізичний смартфон** через додаток Expo Go, оскільки емулятори комп'ютера не завжди підтримують коректний запис відеопотоку.
- Відкрийте чат одночасно на двох пристроях (або на телефоні та у веб-браузері), щоб переконатися, що відеокружечок надсилається та відтворюється у реальному часі без затримок.
