## 🚀 Що реалізуємо у цьому завданні

Справжній месенджер не може існувати без миттєвих сповіщень. Коли користувач закриває додаток або блокує смартфон, він має вчасно дізнаватися про нові повідомлення та події.

У цьому завданні ми впроваджуємо повний цикл системних **Push-сповіщень**:
1. **Збереження Push-токенів:** Отримуємо унікальний `ExponentPushToken` на пристрої та зберігаємо його в базі даних Convex.
2. **Бекенд-диспетчеризація:** За допомогою `internalAction` та планувальника `ctx.scheduler` Convex відправляє запити до Expo Push Service.
3. **Розумна маршрутизація пушів:**
   - **Нове повідомлення:** Сповіщення надходить усім іншим учасникам кімнати.
   - **Відповідь на повідомлення (Reply):** Автор оригінального повідомлення отримує персональний пуш із цитатою.
   - **Реакція емодзі:** Автор повідомлення дізнається, хто і яке емодзі поставив.
4. **Deep Linking (Глибокі посилання):** Натискання на сповіщення в системній шторці Android автоматично перенаправляє користувача безпосередньо в екран відповідного чату `/(app)/chat/[id]`.

## 🛠 Стек технологій та інструменти

- **Фреймворк:** React Native (Expo SDK 52+ / New Architecture)
- **Маршрутизація:** Expo Router v4 (`router.push`)
- **Клієнтські сповіщення:** [`expo-notifications`](https://docs.expo.dev/versions/latest/sdk/notifications/) & `expo-constants`
- **Транспорт сповіщень:** Expo Push Service API (`https://exp.host/--/api/v2/push/send`)
- **Нативний транспорт Android:** Firebase Cloud Messaging (FCM v1)
- **Бекенд & Realtime DB:** [Convex](https://convex.dev) (`internalAction`, `ctx.scheduler.runAfter`)
- **Автентифікація:** `@convex-dev/auth` (Convex Auth)

## 📋 Чекліст виконання для студента

### 1. Налаштування дозволів та конфігурації проєкту:
- [ ] Встановлено бібліотеки: `npx expo install expo-notifications expo-constants`.
- [ ] У `app.config.ts` (або `app.json`) додано дозволи `POST_NOTIFICATIONS` та `VIBRATE`.
- [ ] Додано плагін `expo-notifications` із налаштуваннями кольору та іконки.
- [ ] Вказано `googleServicesFile: "./google-services.json"` та додано `extra.eas.projectId`.

### 2. Серверна частина у Convex:
- [ ] У `convex/schema.ts` розширено таблицю `users` полем `pushToken: v.optional(v.string())`.
- [ ] У `convex/users.ts` реалізовано мутацію `savePushToken`.
- [ ] Створено файл `convex/pushNotifications.ts` з внутрішнім екшеном `sendPushNotification`.
- [ ] У `convex/messages.ts` (мутація `sendMessage`) реалізовано відправку пушів учасникам кімнати та автору повідомлення при відповіді (Reply).
- [ ] У `convex/reactions.ts` (мутація `toggleReaction`) реалізовано відправку пуша автору повідомлення при додаванні емодзі-реакції.

### 3. Клієнтська частина та Deep Linking:
- [ ] Створено хук `hooks/usePushNotifications.ts`.
- [ ] Налаштовано системний канал сповіщень для Android (`setNotificationChannelAsync`).
- [ ] Налаштовано обробку сповіщень у Foreground-режимі (`setNotificationHandler`).
- [ ] Реалізовано перехід у відповідну кімнату чату `/(app)/chat/[id]` при кліку на сповіщення (у фоновому режимі та при холодному старті через `useLastNotificationResponse`).
- [ ] Хук `usePushNotifications()` підключено у `components/InitialLayout.tsx`.

### 4. Тестування на пристрої:
- [ ] Токен успішно записується в таблицю `users` у Convex Dashboard.
- [ ] Успішно надіслано тестове сповіщення через [Expo Push Tool](https://expo.dev/notifications).
- [ ] Протестовано отримання повідомлення у згорнутому стані додатку.
- [ ] Перевірено перехід у чат при натисканні на банер сповіщення.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Бейдж непрочитаних повідомлень на іконці додатку:**
   - Використовуйте `Notifications.setBadgeCountAsync(count)` для відображення кількості непрочитаних повідомлень безпосередньо на іконці додатку в лаунчері смартфона.
2. **Вимкнення сповіщень для окремої кімнати (Mute Notifications):**
   - Додайте у таблицю кімнат або користувача прапорець `isMuted`, щоб користувач міг заглушити сповіщення для надто активних чатів.
3. **Кастомний звук для повідомлень:**
   - Налаштуйте у системному каналі Android власний звуковий файл для сповіщень месенджера.
