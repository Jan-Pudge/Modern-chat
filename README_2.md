# Домашнє Завдання 9: Жести, Цитування та Екосистема Профілів у Modern Chat 💬✨

Це домашнє завдання є логічним та технічним продовженням розробки мобільного месенджера **Modern Chat**.
- Базова частина була побудована у **ДЗ 7** (інструкції `01–05` у папці `lesson-07-module-05/docs-home-work-modern-chat`).
- Дії з повідомленнями, медіафайли у Convex Storage та індикатор набору тексту додані у **ДЗ 8** (інструкції `06–08` у папці `lesson-08-module-05/home-work-08`).

У цьому модулі ми піднімаємо наш додаток на рівень топових сучасних месенджерів (**Telegram, WhatsApp, iMessage**), додаючи плавні мобільні жести (Gestures & Physics Animations), швидкі відповіді на повідомлення із цитуванням та персоналізовану екосистему профілів учасників.

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo SDK 52+ (Expo Router v4)
- **Анімації та жести:** `react-native-gesture-handler` + `react-native-reanimated` 3 (фізика пружин `withSpring`, порогові зміщення, `Gesture.Pan`)
- **Стилізація:** Tailwind CSS (NativeWind v4) з єдиною палітрою кольорів `constants/theme.ts`
- **Бекенд & Realtime DB:** [Convex](https://convex.dev)
- **Хмарне сховище файлів:** Convex Storage (для надсилання медіаповідомлень та завантаження аватарок)
- **Автентифікація:** `@convex-dev/auth` (Convex Auth)
- **Вибір медіа:** `expo-image-picker`
- **Іконки:** `@expo/vector-icons` (`Ionicons`)

## 📋 Чекліст виконання для студента

### 1. Відповіді на повідомлення та цитування (Інструкція 09):
- [ ] Свайп будь-якого повідомлення вправо плавно висуває іконку відповіді `arrow-undo` та переводить інпут у режим відповіді.
- [ ] У меню довгого натискання на повідомлення додано пункт «Відповісти».
- [ ] Над полем вводу відображається плаваюча панель `ReplyPreviewBar` з ім'ям адресата, текстом повідомлення та кнопкою скасування "✕".
- [ ] Надіслане повідомлення містить акуратний блок цитати з кольоровою смужкою зліва та ім'ям автора оригінальної репліки.
- [ ] Цитування коректно працює як для текстових повідомлень, так і для надісланих фотографій.

### 2. Профіль користувача та екран співрозмовника (Інструкція 10):
- [ ] На екрані профілю відображається аватар, ім'я, нікнейм `@username`, email та статус/bio.
- [ ] Додано блок статистики: кількість надісланих повідомлень та кількість створених кімнат.
- [ ] У модальному вікні `EditProfileModal` можна змінити фото, обравши його з галереї телефону.
- [ ] Фотографія успішно завантажується у Convex Storage та оновлює профіль.
- [ ] При натисканні на ім'я або аватар автора повідомлення у чаті відкривається публічний екран `app/user/[id].tsx` з його даними та статистикою.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Тактильний відгук (Haptic Feedback):**
   - Додайте вібрацію телефону за допомогою `expo-haptics` при успішному спрацьовуванні свайпу для відповіді або відкритті меню довгого натискання:
     ```bash
     npx expo install expo-haptics
     ```
   - Викликайте `Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)` у момент фіксації порогу жесту!

2. **Швидкі реакції емодзі на повідомлення (Message Reactions):**
   - Додайте спливаюче меню вибору швидких реакцій (👍, ❤️, 😂, 🔥, 😮) при подвійному тапі на повідомлення.
   - Відображайте лічильники реакцій під бульбашкою повідомлення!

## 💡 Поради щодо тестування

- **Тестування жестів:** Найкраще тестувати свайпи на реальному фізичному пристрої через **Expo Go** або у симуляторі з увімкненою емуляцією сенсорного екрану.
- **Тестування цитування та взаємодії між користувачами:** Запустіть додаток під двома різними акаунтами (наприклад, у вікні браузера `npm run web` та на мобільному телефоні / симуляторі).
- Спробуйте відповісти на повідомлення іншого користувача та перевірте, як цитата синхронізується в реальному часі на обох екранах.
- Натисніть на аватар співрозмовника, щоб переконатися, що його профіль та лічильники повідомлень відображаються коректно.
