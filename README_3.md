# Домашнє Завдання 11: Голосові Повідомлення та Реакції у Modern Chat 💬🎙️🔥

Це домашнє завдання є логічним та технічним продовженням розробки мобільного месенджера **Modern Chat**.
- Базова частина, авторизація та кімнати побудовані у **ДЗ 7** (`lesson-07-module-05/docs-home-work-modern-chat`).
- Редагування/видалення повідомлень, відправка фото у Convex Storage та індикатор набору тексту додані у **ДЗ 8** (`lesson-08-mosule-05/home-work-08`).
- Відповіді на повідомлення (Swipe-to-Reply) та кастомізація профілів реалізовані у **ДЗ 9** (`lesson-09-module-06/home-work-09`).
- Свайп карточок кімнат для видалення реалізовано у **ДЗ 10** (`lesson-10-module-06/home-work-10`).

У цьому завданні ми перетворюємо наш додаток на повноцінний мультимедійний месенджер рівня **Telegram** та **Discord**, додаючи запис і відтворення голосових повідомлень на базі сучасного офіційного пакета **`expo-audio`** та систему інтерактивних реакцій емодзі у реальному часі.

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo SDK 52+ (Expo Router v4)
- **Робота зі звуком:** [`expo-audio`](https://docs.expo.dev/versions/latest/sdk/audio/) (офіційний сучасний модульний пакет замість застарілого `expo-av`)
- **Стилізація:** Tailwind CSS (NativeWind v4) з єдиною палітрою кольорів `constants/theme.ts`
- **Бекенд & Realtime DB:** [Convex](https://convex.dev)
- **Хмарне сховище файлів:** Convex Storage (для зберігання `.m4a` аудіофайлів)
- **Анімації та жести:** `react-native-gesture-handler` + `react-native-reanimated`
- **Іконки:** `@expo/vector-icons` (`Ionicons`)

## 📋 Чекліст виконання для студента

### 1. Голосові повідомлення (Інструкція 12):
- [ ] Встановлено та налаштовано бібліотеку `expo-audio` (системні дозволи для мікрофона додано у конфігурацію додатку).
- [ ] У схемі бази даних `convex/schema.ts` таблицю `messages` розширено полями `audioUrl`, `audioStorageId`, `audioDuration`.
- [ ] У компоненті `ChatInput.tsx` додано кнопку мікрофона, яка перемикає інтерфейс у режим запису звуку.
- [ ] Під час запису відображається анімований червоний індикатор та таймер секунд у реальному часі.
- [ ] Є можливість скасувати запис або надіслати його одним дотиком.
- [ ] Аудіофайл успішно завантажується у Convex Storage та зберігається як повідомлення.
- [ ] У списку повідомлень голосові відображаються через компонент `VoiceMessagePlayer.tsx` з кнопкою Play/Pause, таймером та смужкою прогресу.

### 2. Реакції на повідомлення (Інструкція 13):
- [ ] Створено таблицю `messageReactions` або відповідну структуру в схемі Convex.
- [ ] Написано мутацію `toggleReaction`, яка додає реакцію користувача або знімає її при повторному натисканні.
- [ ] Довге натискання (або подвійний тап) на бульбашку повідомлення відкриває красиве меню зі швидкими емодзі (👍, ❤️, 😂, 🔥, 😮, 😢).
- [ ] Під бульбашкою повідомлення відображаються акуратні бейджі з підрахованими реакціями.
- [ ] Якщо поточний користувач уже поставив цю реакцію, бейдж візуально підсвічується акцентним кольором.
- [ ] Зміна реакцій синхронізується між усіма користувачами чату миттєво в реальному часі.

## 🌟 Бонусні завдання (За бажанням, для додаткових балів)

1. **Тактильний відгук (Haptic Feedback) під час запису та реакцій:**
   - Використовуйте `expo-haptics` для легкої вібрації при старті/зупинці запису аудіо та при встановленні реакції:
     ```typescript
     import * as Haptics from "expo-haptics";
     await Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
     ```

2. **Анімована звукова хвиля (Audio Waveform):**
   - Додайте візуалізацію амплітуди звуку під час запису за допомогою властивості `metering` або анімованих смужок на `react-native-reanimated`.

## 💡 Поради щодо тестування

- Для тестування мікрофона найкраще використовувати **реальний фізичний пристрій** через додаток Expo Go, оскільки емулятори можуть вимагати додаткового налаштування аудіовходу у системі.
- Відкрийте чат одночасно під двома різними акаунтами, щоб переконатися, що голосове повідомлення та реакції з'являються у співрозмовника миттєво без перезавантаження сторінки.
