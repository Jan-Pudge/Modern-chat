# Домашнє Завдання 8: Просунутий Функціонал Modern Chat 💬🚀

Це домашнє завдання є логічним та технічним продовженням розробки додатку **Modern Chat**, базову версію якого ви побудували у попередньому завданні (інструкції `01-05` у папці `lesson-07-module-05/docs-home-work-modern-chat`).

У цьому модулі ми перетворюємо базовий чат на повноцінний сучасний месенджер рівня **Telegram / Slack / Discord**, додаючи розширені можливості взаємодії в реальному часі.

---

## 📚 Зміст Інструкцій

| № | Назва інструкції | Що реалізуємо |
|---|---|---|
| **06** | **[Редагування та видалення повідомлень](./06-message-actions.md)** | Мутації `editMessage` та `deleteMessage`, позначка `(ред.)`, меню довгого натискання (Long Press), скасування редагування |
| **07** | **[Відправка зображень у чат (Media Messages)](./07-media-messages.md)** | Вибір фото через `expo-image-picker`, завантаження файлів у сховище **Convex Storage**, повноекранний перегляд фото у `ImageViewerModal` |
| **08** | **[Індикатор набору тексту (Typing Indicator)](./08-typing-indicator.md)** | Таблиця `typingIndicators`, мутація `setTyping` з тротлінгом 1.5 с, реактивний хук `getTypingUsers`, плавні три крапки `TypingDots` |

## 🛠 Стек технологій

- **Фреймворк:** React Native / Expo (Expo Router v4)
- **Стилізація:** Tailwind CSS (NativeWind v4) з єдиною палітрою кольорів `constants/theme.ts`
- **Бекенд & Realtime DB:** [Convex](https://convex.dev)
- **Хмарне сховище файлів:** Convex Storage
- **Автентифікація:** `@convex-dev/auth` (Convex Auth)
- **Іконки:** `@expo/vector-icons` (`Ionicons`)

## 📋 Чекліст виконання для студента

1. [ ] **Редагування повідомлень:**
   - Користувач може редагувати лише власні повідомлення.
   - Біля відредагованого повідомлення з'являється позначка `(ред.)`.
   - Режим редагування можна зручно скасувати хрестиком над полем вводу.
2. [ ] **Видалення повідомлень:**
   - Користувач може видалити власне повідомлення через діалог підтвердження.
   - При видаленні останнього повідомлення в кімнаті інформація в списку чатів коректно оновлюється.
3. [ ] **Робота з фотографіями:**
   - Дозволено вибір зображення з медіатеки телефону.
   - Перед відправкою показується прев'ю обраної картинки з можливістю скасування.
   - Картинка завантажується у Convex Storage та відображається у чаті.
   - При натисканні на картинку відкривається повноекранний модальний переглядач.
4. [ ] **Індикатор "Користувач друкує...":**
   - Відображається лише тоді, коли інший користувач друкує в цій же кімнаті.
   - Зникає автоматично через 3 секунди неактивності.

## 💡 Поради щодо тестування

- Для перевірки роботи в реальному часі запустіть додаток одночасно на двох пристроях або у двох вкладках/вікнах (наприклад, симулятор iOS + Android-емулятор або Expo Web + мобільний телефон).
- Увійдіть під двома різними тестовими обліковими записами, відкрийте одну й ту саму кімнату та протестуйте відправку тексту, фотографій та індикатор набору тексту.
